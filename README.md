# ✨ Overview

Modern AI coding tools are powerful, but most workflows still happen in disconnected chat windows.

Kanban Agent transforms AI development into a structured production pipeline by combining:

- 🧠 Autonomous AI Agents
- 📋 Kanban Workflow Management
- 🔍 Integrated Review Systems
- ⚡ Multi-Agent Execution
- 🔌 MCP Integrations
- 📊 Token & Runtime Tracking

Instead of:

> Ask AI → Copy → Paste → Repeat

Kanban Agent enables:

> Create Task → Assign Agent → Review Changes → Approve → Ship

---

# 🧩 Core Workflow

```text
Backlog
   ↓
To Do
   ↓
Assign AI Agent
   ↓
In Process
   ↓
AI Generates Changes
   ↓
In Review
   ↓
Approve / Reject
   ↓
Done
````

---

# 📌 Fixed Board Structure

Kanban Agent uses a production-oriented workflow system.

| Column     | Purpose                       |
| ---------- | ----------------------------- |
| My Skill   | AI presets and role templates |
| Backlog    | Ideas and pending tasks       |
| To Do      | Ready-to-start work           |
| In Process | Active AI execution           |
| In Review  | Code review and approvals     |
| Done       | Completed work                |
| Archive    | Historical storage            |

---

# 🧠 MCP Support

Kanban Agent supports **Model Context Protocol (MCP)** integrations.

This enables external systems to interact with the board directly.

## Example Use Cases

* Create cards from Discord
* Sync GitHub Issues
* Trigger AI reviews automatically
* Connect internal studio tools
* Remote task orchestration

# 🔍 Review Pipeline

The review system is designed for developer productivity.

## In Review Features

* Git-style diff previews
* Plastic SCM-style review flow
* AI-generated summaries
* Approve / Reject buttons directly inside cards
* File change tracking
* Review feedback loops
